# Quran Data Integrity

Quran Arabic text is never generated by the application or by an LLM. Production sync uses Quran Foundation's official JavaScript/TypeScript SDK through the server entrypoint.

## Sync

Run:

```bash
npm run quran:sync
```

The command requires server-side `QF_CLIENT_ID`, `QF_CLIENT_SECRET`, and `QF_ENV=production` for production data. It imports:

- 114 chapters;
- 604 pages;
- 6,236 verses;
- Uthmani text;
- word order, page, line, verse, and juz metadata where available.

## Validation

Run:

```bash
npm run quran:validate
```

Validation checks chapter/page/verse/word counts, verse-key uniqueness, juz and page ranges, and whether a full memorization cycle can be constructed from imported page bands.

## Browser Translation

The root layout sets `translate="no"` and `meta name="google" content="notranslate"`. Quran text containers are rendered with `translate="no"`, `lang="ar"`, and RTL direction.
